# ZIP 1 — Weldcom Dashboard Frontend V1

Bên trong zip này có project:

```text
frontEnd/weldcom-ai-operations-dashboard/
```

Đây là giao diện React + Vite + Tailwind + Recharts cho màn dashboard bạn chọn.

Chạy nhanh:

```powershell
cd frontEnd\weldcom-ai-operations-dashboard
npm install
npm install @tailwindcss/postcss
copy .env.example .env
npm run dev
```

Mặc định chạy mock data. Khi backend sẵn sàng, đổi `VITE_DATA_MODE=api`.
